# ふたりの家計

Studio Next とは無関係の、夫婦で使う家計ダッシュボードです。単一の HTML ファイルで完結しています。

- `index.html` … アプリ本体（CSS・JS・案内役の絵をすべて内包）
- `../worker/api/src/kakei.ts` … 暗号文を預かるサーバー側

貯蓄・ローン・その月の収入と支出を**月に一度だけ書き写す**と、
純資産・月ごとの収支と総合計・ローンの完済予定・入金予定・これまでの推移が1枚で出ます。

## 月ごとの収支

収入と支出は**月ごとに1行**持ちます（`months`）。行は `{ym:"2026-10", income, sides, expense}` で、
`sides` は**種目のid → 金額**の対応表です。種目そのものは `sideKinds`（`{id, name, who}`。
`who` は `"Y"`＝ゆきこ／`"M"`＝まさひろ）に1組だけ持ち、各月はidで参照します。
名前を変えても過去の月の金額はそのまま残ります。

種目を消すと、各月の `sides` からその金額も消します。残すと合計に出てこない幽霊になるためです。
逆に、一覧に無いidが `sides` に残っていても、人ごと・種目ごとの合計には混ざりません
（`sideKinds` を軸に足すので）。これはテストで固定しています。
ダッシュボードには新しい月を上にして並べ、いちばん下に**総合計**の行を置きます。
上のカードは**いちばん新しい月**の数字を出します。

同じ月が2行あっても勝手にまとめません。入力の誤りなので、並べて気づけるようにしています。

月ごとに分ける前の形（収入と支出が1組だけ）で保存されていたものは、
`updatedAt` の月の1行として引き継ぎます。種目に分ける前の形（ゆきこ／まさひろの2つだけ）は、
その人の種目があればそこへ、無ければ「副業（名前）」という種目を作って引き継ぎます。

## マネーフォワードとの連携について

**自動連携はできません。** マネーフォワードは個人が作ったアプリ向けにデータを渡す
仕組み（API）を公開していないためです。ログイン情報を預かって自動取得する方法は
規約と安全性の両面で採りません。そのぶん、口座のパスワードをどこにも預けずに済みます。

運用は「マネーフォワードの画面を見ながら、月に一度、合計だけを書き写す」です。
アプリ内の **メニュー → 使いかた** に同じ手順を書いてあります。

## どこに置いてあるか

**相手は Claude を使っていなくて構いません。** ふつうのWebページとして開けます。

```
https://karasui1014.github.io/studio-next/kakei/
```

| | 役目 |
|---|---|
| **GitHub Pages** | アプリ本体（HTML1枚）を配る。`public/kakei/` の中身がそのまま出る |
| **Cloudflare Worker** | 数字を預かる。`studio-next-api` の `/api/kakei` |
| **KV** | 暗号文の置き場所。キーは `kakei:v1:home` |

Worker も KV も、**中身を復号できません**。合言葉から作った鍵で端末が暗号化してから
送るので、預けてあるのは意味のない文字列だけです。

## 合言葉と、ふたりでの共有

**合言葉はひとつを2人で共有します。** 人ごとの出し分けはありません。

| | |
|---|---|
| 鍵の導出 | PBKDF2-SHA256、25万回、16バイトのランダムsalt。**512bitを一度に導出**する |
| 前半32バイト | 中身を暗号化する鍵（AES-GCM 256bit）。**端末から出ない** |
| 後半32バイト | サーバーに「書いてよい人だ」と示す札（token） |
| サーバーが持つもの | `sha256(token)` と、暗号文・salt・版番号だけ |
| 解錠中の鍵 | `sessionStorage` に期限つき。タブを閉じれば消える |
| 失効 | 最後の操作から1時間。`visibilitychange` と30秒ごとの点検で施錠 |

**合言葉は8文字以上**を必須にしています。ネット上に暗号文を置くので、
4桁の暗証番号では総当たりに耐えられないためです（Worker側も1分20回で足止めします）。

忘れると誰にも開けません（復旧手段はありません）。ヒントを1つ登録できます。

Web Crypto が使えない環境（一部の `file://` など）では中身を開かず、
https から開き直すよう案内します。

## 同時に書いたとき

保存には「自分が読んだときの版番号」を添えます。ズレていたらサーバーが 409 を返し、
アプリは**黙って上書きせずに**選ばせます。

- 「相手の数字を読み込む」… 自分の変更は消える（この端末に控えは残ります）
- 「自分の数字で上書きする」… 相手の変更が消える

サーバーにつながらないときは、この端末の localStorage にだけ保存し、
つながったら保存し直すよう案内します。

## 入れる数字

| 項目 | 単位 | メモ |
|---|---|---|
| 貯蓄の合計 | 万円 | 銀行・証券・現金をぜんぶ足した額。口座ごとには分けない |
| 月ごとの収入と支出 | 万円 | 月に1行。本業の収入／支出／副業（種目ごと） |
| 副業の種目 | — | 名前と「だれの副業か」。ここで作った種目が、月の入力欄に並ぶ |
| ローン | 万円・％ | 残高／毎月の返済額／金利。当初の借入額は任意 |
| 入金予定 | 日 | 名前と「毎月何日」、そして**どこに入るか**（本業の収入／どの副業） |

金額はすべて**万円**です。小数（`9.5`）も入ります。

## 計算していること

- **純資産** = 貯蓄 − ローン残高の合計
- **その月の収入** = 本業の収入 ＋ 副業（種目をぜんぶ足したもの）
- **その月の収支** = その月の収入 − その月の支出
- **総合計** = すべての月の収入・支出・収支をそれぞれ足したもの
- **完済まで** … 元利均等返済として、残高 `B`・毎月返済額 `P`・月利 `i`（年利 ÷ 12）から
  `n = -log(1 - B·i / P) / log(1 + i)`。金利0なら `B / P`。
  `P ≤ B·i`（返済額が利息に届かない）ときは計算せず、その旨を画面に出します。
- **これから払う利息** = `P·n − B`
- **入金予定の行を押すと、その場で金額を入れられる**。行は `link` を持ち、
  `"income"`＝本業の収入、種目のid＝その副業を指す。押すと「どこに入れる／どの月／いくら」の
  3つだけ聞き、その月の行が無ければ作って書き込む。行き先を選び直すと `link` も覚え直す。
  指していた種目が消えていた場合は、紐づいていない扱いにして選び直してもらう。
- **次の入金日** … 毎月○日から次に来る日を出し、「あと◯日」で表示する。
  今日が当日なら今日を返す（もらう日を過ぎてから翌月へ送る）。
  その月に無い日（2月31日など）は、その月の最終日に寄せる。

いずれも `kakei/__tests__/keisan.test.ts` で固定してあります。テストは
`index.html` から関数だけを取り出して評価するので、画面の作りを変えても壊れません。

## 記録と推移

「保存する」を押すたびに、その月の `{貯蓄, ローン残高}` を1点だけ残します
（同じ月に何度押しても上書き。最大240か月ぶん）。

グラフは**月ごとの縦棒**です（直近12か月・貯蓄とローン残高の2本並び）。
折れ線だったころは2点ないと描けませんでしたが、棒なら1か月ぶんから出ます。
たてじくの上端は桁をそろえたきりのいい数に丸めます（例: 2800 → 3000）。

## 仕組み

数字は端末で暗号化してから Worker に預け、開くたびに取ってきて復号します。
サーバーもデータベースの中身も読めません。

- 保存前の内容は localStorage に下書きとして常に控えます。保存に失敗しても消えません。
- Google Fonts の `<link>` は `media="print" onload="this.media='all'"` で読み込みます。
  ふつうに書くと、フォントが届くまで後ろの `<script>` が動かず画面が白いままになります。
- 画面に戻ってきたとき、書きかけが無ければ自動で最新を読み直します。
  手動で読み直すときは メニュー → 「最新を読み込む」。
- 小さい画面（メニューや入金の入力）を開いているあいだは、後ろの本文を
  `position:fixed` で止めます。`overflow:hidden` だけでは iPhone の Safari が
  後ろを動かしてしまうためです。閉じると元の位置へ戻します。
  どの画面にも右上に「✕」と、下に大きな「← 戻る」を置いています。

## 案内役とアイコン

引き継ぎ書と同じ探偵の絵を使っています。元絵は
`shukatsu/assets/character-sheet.webp`、切り出し済みの画像は
`shukatsu/index.html` の `ART` にあり、`build-art.py` がそれをそのまま持ってきます。
**アプリ内にキャラクター名や肩書きは出しません。** 吹き出しはセリフだけです。

### 背景

地は2枚重ねです（`body::before`）。上からの温かい光と、右下の浅葱の差し色。
その上に `body::after` で紙のざらつき（SVGのノイズ）を薄くかぶせます。
画像ファイルは持たず、すべてCSSとdata URIで完結します。

> 以前は方眼の点（22px間隔）も敷いていましたが、**文字が読みにくい**という声があり
> やめました。戻すなら `body::before` の `background` の先頭に
> `radial-gradient(var(--grid) 1px, transparent 1.6px) 0 0/22px 22px,` を足します。

`position:fixed` で敷いているので、スクロールしても背景は動きません
（`background-attachment:fixed` は一部のスマホで描画が重くなるため使っていません）。
カード類は `color-mix` で少しだけ透かし、奥の方眼が見えるようにしています。
印刷時は両方とも消えます。

濃さは `--glow` `--glow2` の2つで決まります。暗いときの値も別に持っています。

### 明るい・暗いの切り替え

既定は「自動」（端末の設定にしたがう）。メニュー → 見た目 で
**自動／明るい／暗い**を選べます。選んだときだけ `<html>` に `data-theme` を付け、
`kakei.v1.theme` に覚えます。**その端末だけの設定**で、相手の画面は変わりません。

合言葉を入れる前の画面にも効かせたいので、鍵の仕組みより先に読み込んでいます。
あわせて `<meta name="theme-color">` も書き換え、スマホの上下の帯の色を合わせます。

### 案内役のひとこと

`LINES` に場面ごとの言葉を持ち、開くたびに1つ選びます（`pickFrom`）。
**直前に出したものは避ける**ので、2回続けて同じ言葉にはなりません。

場面は 6つ: `start`（まだ何も無い）／`debt`（純資産がマイナス）／`spend`（支出超過）／
`ok`（ローンありでプラス）／`great`（借金なし）／`side`（副業が収入の15%以上）。

数字が悪いときでも責めません。事実は数字が示しているので、言葉は前を向かせる役に徹します。
「どの場面にも3つ以上ある」「責める語を混ぜない」はテストで固定しています。

配色も同じシートの COLOR PALETTE から取っています
（生成り `#F5F1E8` ／ タン `#D9B98C` ／ 浅葱 `#4C888C` ／ 焦茶 `#8A7A67` ／ 墨緑 `#3E4540`）。

### アイコン

```bash
python3 kakei/assets/build-icons.py
```

| ファイル | 用途 |
|---|---|
| `icon-32.png` / `icon-48.png` | ブラウザのタブ（余白を詰めて顔を大きく） |
| `apple-touch-icon.png` (180) | iOSのホーム画面。**角丸なし**（iOSが自分で丸める） |
| `icon-192.png` / `icon-512.png` | Androidのホーム画面・スプラッシュ |
| `icon-maskable.png` (512) | Androidのアダプティブ用。外側20%が削られても顔が残る余白 |

出力先は `public/kakei/icons/`。あわせて `index.html` の `FAVICON`
（48pxのdata URI）も差し替わり、起動時に `<link rel="icon">` として貼られます。
外部ファイルを読めない開き方でもタブに出るようにするためです。

引き継ぎ書のアイコンは深い浅葱の地ですが、こちらは**白系**です。
ただし真っ白だと、白いタブやホーム画面で輪郭が消えるので、生成りの地に
**タン色の細い縁**（辺の2.5%）を1本入れています。16pxでも1px弱残ります。
Android のマスク用だけは、縁が削られるので描いていません。

`build-public.py` はアイコンを触りません（引き継ぎ書のアイコンで
潰さないため）。作り直すときは `build-icons.py` を使ってください。
