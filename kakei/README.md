# ふたりの家計

Studio Next とは無関係の、夫婦で使う家計ダッシュボードです。単一の HTML ファイルで完結しています。

- `index.html` … アプリ本体（CSS・JS・案内役の絵をすべて内包）

貯蓄・積立・ローン・毎月の収支を**月に一度だけ書き写す**と、
純資産・ローンの完済予定・積立の到達予定・これまでの推移が1枚で出ます。

## マネーフォワードとの連携について

**自動連携はできません。** マネーフォワードは個人が作ったアプリ向けにデータを渡す
仕組み（API）を公開していないためです。ログイン情報を預かって自動取得する方法は
規約と安全性の両面で採りません。そのぶん、口座のパスワードをどこにも預けずに済みます。

運用は「マネーフォワードの画面を見ながら、月に一度、合計だけを書き写す」です。
アプリ内の **メニュー → 使いかた** に同じ手順を書いてあります。

## 入れる数字

| 項目 | 単位 | メモ |
|---|---|---|
| 貯蓄の合計 | 万円 | 銀行・証券・現金をぜんぶ足した額。口座ごとには分けない |
| 毎月の収入 / 支出 | 万円 | ふたりぶんの手取りと、出ていくお金 |
| ローン | 万円・％ | 残高／毎月の返済額／金利。当初の借入額は任意 |
| 積立 | 万円 | 名前／いまの額／目標／毎月いくら |

金額はすべて**万円**です。小数（`9.5`）も入ります。

## 計算していること

- **純資産** = 貯蓄 ＋ 積立の合計 − ローン残高の合計
- **完済まで** … 元利均等返済として、残高 `B`・毎月返済額 `P`・月利 `i`（年利 ÷ 12）から
  `n = -log(1 - B·i / P) / log(1 + i)`。金利0なら `B / P`。
  `P ≤ B·i`（返済額が利息に届かない）ときは計算せず、その旨を画面に出します。
- **これから払う利息** = `P·n − B`
- **積立の到達予定** = `(目標 − いまの額) ÷ 毎月`

いずれも `kakei/__tests__/keisan.test.ts` で固定してあります。テストは
`index.html` から関数だけを取り出して評価するので、画面の作りを変えても壊れません。

## 記録と推移

「保存する」を押すたびに、その月の `{貯蓄, 積立合計, ローン残高}` を1点だけ残します
（同じ月に何度押しても上書き。最大240か月ぶん）。2点たまるとグラフが出ます。

## 仕組み

書いた数字は `<script type="application/json" id="note-data">` に入り、
「保存する」を押すと**ページ自体を新しいバージョンとして publish し直す**ことで残ります
（`claude.use("artifact")` の `publish`）。サーバーもデータベースも使いません。
引き継ぎ書（`shukatsu/index.html`）と同じ作りです。

- ページの正本は `<style id="app-css">` と `<script id="app-js">` の2つ。
  保存時はこの2つを読み直して完全な HTML を組み立てます（DOM は直列化しません）。
- 保存前の内容は localStorage に下書きとして常に控えます。保存に失敗しても消えません。
- Artifact の外（ローカルのファイルとして開くなど）では localStorage だけで動きます。
- 閲覧権限しかない人が保存を押すと `not_writer` が返り、閲覧専用の表示に切り替わります。
- **同時に二人で書き換えると、あとから保存したほうが残ります**（先の保存は `conflict` になり、
  開き直すよう案内します）。入力は「どちらかが月に一度」にしておくのが安全です。
- Google Fonts の `<link>` は `media="print" onload="this.media='all'"` で読み込みます。
  ふつうに書くと、フォントが届くまで後ろの `<script>` が動かず画面が白いままになります。

## 暗証番号による施錠

**開くには暗証番号が要ります。1時間さわらなければ自動で鍵がかかります。**
画面を隠すだけでは開発者ツールで素通りされるので、**中身そのものを暗号化**しています。

| | |
|---|---|
| 鍵の導出 | PBKDF2-SHA256、25万回、16バイトのランダムsalt |
| 暗号化 | AES-GCM 256bit（改ざんも検知される） |
| 保存の形 | `kakei.v1.vault` = `{salt, iv, ct, at}` |
| 解錠中の鍵 | `sessionStorage` に期限つき。タブを閉じれば消える |
| 失効 | 最後の操作から1時間。`visibilitychange` と30秒ごとの点検で施錠 |

**番号はふたりで共有するもの**です。相手に必ず伝えてください。
忘れると誰にも開けません（復旧手段はありません）。ヒントを1つ登録できます。

Web Crypto が使えない環境（一部の `file://` など）では中身を開かず、
https から開き直すよう案内します。

## 案内役

引き継ぎ書と同じ探偵の絵を使っています。元絵は
`shukatsu/assets/character-sheet.webp`、切り出し済みの画像は
`shukatsu/index.html` の `ART` にあり、`build-art.py` がそれをそのまま持ってきます。
**アプリ内にキャラクター名や肩書きは出しません。** 吹き出しはセリフだけです。

配色も同じシートの COLOR PALETTE から取っています
（生成り `#F5F1E8` ／ タン `#D9B98C` ／ 浅葱 `#4C888C` ／ 焦茶 `#8A7A67` ／ 墨緑 `#3E4540`）。

- 口座番号・パスワード・暗証番号は入力させません。「いくらあるか」だけを見る場所です。
- 明細は扱いません。合計だけを月に一度書き写す設計です。
