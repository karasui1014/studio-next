# AI音楽部 Studio — V1からV2への移植内容

軍配スキル（マーケティング検討）向けの引き継ぎメモです。
「V2でユーザーが実際に使える機能は何か」をまとめています。

- 作成日：2026-08-08
- 対象：`~/AI音楽部 Studio Next`（Version 2、開発中）
- 比較元：`~/AI Music Studio`（Version 1、本番稼働中・現行サイト）

---

## 結論

**V1が自前で持っていた制作ツール・データ機能は、V2にすべて移植済みです。**
移植は「ロジックは無改変でコピーし、UIだけを新しく作り直す」方式で行っており、
V1時代のテスト**141件がV2でも全て通過**しています（機能が壊れていない証拠）。

⚠️ **「自前で持っていた」の範囲に注意**（2026-08-09追記）

V1の「ツール」ページには、V1自身が実装した機能（下の一覧）とは別に、
**外部サイトへのリンク集**（絵コンテツール／字幕自動生成ツール／ギターコードTAB／
マスタリング自動生成ツール／楽曲批評ツール／Seedance Batch Studio）が並んでいた。
これらはV1のコード資産ではなく、それぞれ独立したWebサイトへの入口にすぎない。

**この5つ（+1）は「移植」の対象にしておらず、V2には存在しない。**
以前の版の本メモは「V1で公開していた制作ツール・データ機能は、V2にすべて移植済み」
とだけ書いており、この外部リンク集を含むかのように読めた。誤解を招く書き方だったため、
「V1が自前で持っていた」と明記し、範囲をはっきりさせた。

## 移植の進め方（品質の裏付け）

1. V1の`src/lib/tools/`配下のロジックだけをコピー
2. import先をV2用の`deps.ts`に付け替え（ロジックの中身は一切変更しない）
3. V1由来のテストをV2でそのまま実行し、全件通過することを確認
4. UI（画面の見た目）だけをV2のデザインで新規に作成

この手順により、**見た目は刷新しつつ、動作の正しさはV1の実績あるテストで担保**しています。
